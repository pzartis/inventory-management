Factory Inventory Management System

A demo full-stack app: Vue 3 single-page frontend, Python FastAPI backend, and in-memory mock data loaded from JSON files. No database.

Data flow

Four filters (time period, warehouse, category, order status) are held in shared state and sent as query params. Raw responses are stored in refs such as allOrders and inventoryItems; all derived values are computed properties. Inventory endpoints ignore the month filter because inventory has no time dimension.

Observations

Client and server are out of sync. client/src/api.js calls task endpoints (getTasks, createTask, toggleTask, deleteTask) and purchase-order endpoints (POST /purchase-orders, GET /purchase-orders/{id}). server/main.py defines no such routes, and has no POST, PUT or DELETE routes at all. A CreatePurchaseOrderRequest model exists but is unused. Those features will fail against the current backend.
  • CORS allows all origins and the API base URL is hard-coded to localhost:8001; fine for a demo, not for deployment.
  • All data is read from memory, so there is no write path and no persistence.
